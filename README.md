# Herwani Kondru — Digital HR Portfolio

## Publish for free with GitHub Pages

1. Create/sign in to GitHub.
2. Create a new PUBLIC repository named `herwani-kondru.github.io`.
3. Upload `index.html`, `style.css`, the `assets` folder, and `portfolio.pdf`.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. Your portfolio will be available at:
   `https://herwani-kondru.github.io/`

The exact GitHub Pages URL can take a few minutes to become active.
